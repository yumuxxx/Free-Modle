## 两份每日榜单

### 1. 每日受欢迎排行（Popular）

**口径**：按 GitHub star 总数排序。

**意义**：star 高 = 用的人多 = 生态好、坑被人踩过、遇到问题搜得到答案。

**适合**：选型时求稳，不想当小白鼠。

### 2. 每日新品排行（Rising）

**口径**：按**近期 star 增速**排序（近 7 天新增 star / 项目年龄），新项目和高增速项目优先。

**意义**：增速快 = 正在解决某个真实痛点 = 可能代表新趋势。

**适合**：想了解技术走向，愿意承担早期风险。

## 排名怎么读

榜单里每条包含：

- **项目名**（owner/repo）
- **star 总数** + 近 7 天增减
- **一句话定位**
- **语言** / **许可证**
- **最近推送时间** —— 判断是否还在维护的**最重要指标**

### 三个避坑信号

1. **`pushed_at` 超过 6 个月** → 项目大概率停更，慎用于生产
2. **`archived: true`** → 作者已明确放弃，直接排除
3. **star 高但 issue 大量无人回复** → 维护者已失去兴趣
