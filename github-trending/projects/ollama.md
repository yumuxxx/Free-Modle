## 一句话定位

在本机跑开源大模型的事实标准工具。一条命令拉模型，一条命令启动对话。

## 为什么它是第一名

184K star、当日仍在提交，且已经形成生态：
- 模型库覆盖主流开源模型
- 图形客户端（如 Open WebUI）、IDE 插件、Agent 框架都默认支持它
- 遇到问题几乎都能搜到答案

## 快速开始

```bash
# 安装后
ollama pull qwen2.5:7b      # 拉一个模型
ollama run qwen2.5:7b       # 开始对话
ollama list                 # 看已装的
```

## 硬件现实

| 模型规模 | 最低内存 | 体验 |
|---|---|---|
| 7B | 8 GB | 可用，慢 |
| 14B | 16 GB | 尚可 |
| 32B | 32 GB | 好 |
| 70B | 40+ GB | 需量化，最好有独显 |

**没有独显也能跑**，只是速度慢。CPU 推理 7B 模型大约每秒几个 token。

## 什么时候用它

- 数据敏感，不能外传
- 想无限量使用，不担心计费
- 网络不稳，不想依赖云端 API
- 想学习模型原理，方便实验

## 什么时候不用它

- 要最强能力（本地小模型打不过云端大模型）
- 要低延迟批量处理
- 机器资源紧张
