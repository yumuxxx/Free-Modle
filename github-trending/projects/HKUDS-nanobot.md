## 一句话定位

超轻量的自托管个人 AI Agent 框架（Python + Web UI），主打小体量、自己部署、自己掌控。

## 为什么关注它

1. **全场增速之王** —— 2026-02 创建，约 8 个月做到 4.9 万星
2. **自托管 = 免费额度友好** —— 自己部署意味着可以自己决定接哪家免费模型，不被托管服务绑死
3. **出自 HKUDS（港大数据智能实验室）** —— 学术背景，同类还有 LightRAG 等活跃项目

## 适合谁

- 想自己搭一个常驻个人 Agent 的人
- 对数据要留在自己机器上、不愿用托管服务的人
- 想研究轻量 Agent 框架设计的人
