## 一句话定位

把任意网页转成 LLM 可直接消化的干净 markdown / 结构化数据的抓取服务，口号是 "Supercharge your AI agents with data from the web"。

## 为什么关注它

1. **Agent 生态刚需** —— Agent 要用网页内容，绕不开「抓下来 → 洗干净 → 喂模型」这一步，它把这三步打包
2. **已进本仓库追踪** —— 已作为免费额度项同步进 `data/index.jsonl`（免费层可试）
3. **输出对 LLM 友好** —— 直接给 markdown，省掉自己写正文抽取规则

## 适合谁

- 做 RAG / 知识库、需要批量抓文档的人
- 写 Agent 时要让它「自己上网查资料」的人
- 不想维护爬虫和反爬对抗的人

## 风险与注意

- ⚠️ **AGPL-3.0** —— 若用于对外提供服务的商业产品，注意开源义务；自用/内部工具无碍
- ⚠️ 自托管需要 Redis 等依赖，比纯 API 调用重
- 抓取仍受目标站点反爬与 robots 约束，**不是万能**
- 免费层有配额，批量任务前先看限额
