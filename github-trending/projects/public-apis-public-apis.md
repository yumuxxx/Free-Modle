## 一句话定位

社区维护的免费公共 API 大全，按分类列出上千个**无需 key 或免费额度即可用**的 API 入口。

## 为什么关注它

1. **与免费额度主题直接相关** —— 本仓库的核心命题是「不花钱能用的 API」，和 Free-Modle 追踪的免费模型额度是同一条主线
2. **覆盖面极广** —— 不只是 LLM，还有天气、金融、体育、动漫等类别，适合给各种小工具找数据源
3. **MIT + 纯清单** —— 无部署成本、无供应商锁定风险，随时可查可用

## 适合谁

- 想给小项目/爬虫找免费数据源的人
- 不想为每个 API 单独注册付费账号的人
- 需要横向对比某类服务有哪些免费选项的人

## 风险与注意

- ⚠️ **只列入口，不保活** —— 清单里的免费 API 随时可能改为收费或下线，用前必须自己试
- ⚠️ 无 SLA、无配额说明，**批量调用前先看对方文档的限流条款**
- 部分条目链接会腐烂，需要自己校验（这也是本仓库长期活跃、PR 不断的原因）
