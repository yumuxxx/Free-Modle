## 一句话定位

Rust 写的跨平台桌面 All-in-One 助手，在 Claude Code / Codex / OpenCode / OpenClaw 等多个编码 Agent 客户端之间快速切换配置。

## 为什么关注它

1. **本场增速最猛的新面孔** —— 2025-08 创建，约 14 个月冲到 14.8 万星
2. **踩中真实痛点** —— 同时用多个 AI 编码客户端时，配置（key、模型、网关）切换很繁琐，它做成了一键切换
3. **与免费额度主题同源** —— 换客户端往往就是为了换免费额度或换网关，正是本仓库追踪的主线

## 适合谁

- 同时装多个 AI 编码客户端的人
- 想在免费额度和付费渠道之间频繁切换的人
- 需要给不同项目配不同模型/网关的人

## 风险与注意

- ⚠️ **许可证待查** —— 采用前先确认 LICENSE，企业使用尤其要查
- ⚠️ 需在本地保存各客户端的 key/配置，**注意凭证存放安全**
- 项目很新（14 个月），**长期维护性待观察**；明日跟踪重点即确认增速是否持续
- 涉及对第三方客户端的配置改写，升级客户端后可能失效
