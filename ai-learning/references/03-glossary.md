# 03 · 术语表

> 用途：速查。看到不懂的词来这里搜。

---

## 基础概念

| 术语 | 一句话解释 |
|------|-----------|
| **LLM**（大语言模型） | 基于海量文本训练、能生成文字的 AI 模型。你用的对话 AI 基本都是它 |
| **Token** | 模型处理文本的最小单位。1 个汉字约 1–2 个 token，1 个英文单词约 0.75–1 个 token。**计费按 token 算** |
| **上下文窗口** | 单次对话能携带的最大 token 数。超出的内容模型看不到 |
| **提示词（Prompt）** | 你发给 AI 的指令文本 |
| **多模态** | 能处理文字以外的输入（图片、音频、视频） |
| **幻觉（Hallucination）** | AI 编造看似合理但实际错误的信息 |
| **温度（Temperature）** | 控制随机性的参数。低=稳定保守，高=多样发散。写作用低，头脑风暴用高 |

## 使用相关

| 术语 | 一句话解释 |
|------|-----------|
| **系统提示（System Prompt）** | 设定 AI 全局行为的指令，用户通常看不到但生效 |
| **Few-shot** | 在提示词里给几个示例，让 AI 照着格式来 |
| **思维链（Chain of Thought）** | 让 AI "先一步步想再给结论"，复杂推理任务效果明显更好 |
| **RAG**（检索增强生成） | 先从资料库检索相关内容，再让 AI 基于这些内容回答。解决"AI 不知道你内部文档"的问题 |
| **Agent（智能体）** | 能自己规划步骤、调用工具、多轮执行直到完成任务的 AI 应用 |
| **MCP** | 一种让 AI 连接外部工具/数据的标准协议。有了它，AI 能操作你的文件、调用你的 API |

---

## 部署相关

| 术语 | 一句话解释 |
|------|-----------|
| **API** | 用代码调用 AI 的接口，按量计费 |
| **量化（Quantization）** | 压缩模型精度以减小体积、降低显存占用，代价是精度略降 |
| **推理（Inference）** | 模型实际生成内容的过程，区别于"训练" |
| **微调（Fine-tuning）** | 在已有模型上用你自己的数据再训练，让它更懂你的领域 |
| **本地部署** | 模型跑在自己机器上，数据不出本机 |
| **反代** | 用一个统一接口转发到多家 AI 服务。好处：换供应商不用改代码，还能做限流和统计 |

---

## 常见坑

| 术语 | 一句话解释 |
|------|-----------|
| **Lost in the middle** | 长上下文中，中段内容容易被模型忽略。重要信息放首尾 |
| **速率限制（Rate Limit）** | 单位时间内的请求/ token 上限。免费额度尤其严格 |
| **上下文溢出** | 输入超出窗口，报错或被静默截断 |
| **提示词注入** | 恶意构造的输入让 AI 忽略原有指令、执行攻击者意图。**处理不可信内容时必须防范** |
