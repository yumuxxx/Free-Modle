# 01 · 对话式 AI 使用指南

> 目标：从"会把 AI 当搜索引擎用"变成"会把 AI 当协作用"。
> 前置：先读 [`../references/01-prompt-engineering-basics.md`](../references/01-prompt-engineering-basics.md)。
> 预计时间：半天。包含 4 个必须动手的练习。

---

## 第 1 课：先搞懂你在用什么

### 1.1 对话式 AI 的三个特性

| 特性 | 意味着什么 | 实际影响 |
|------|-----------|----------|
| **有记忆（在同一会话内）** | 前面说过的话它记得 | 可以逐步细化，不用每次重述背景 |
| **无记忆（跨会话）** | 关掉窗口就忘 | 重要的背景每次都要给，或存成模板 |
| **会猜** | 需求模糊时它会自行补全 | 补全的方向不一定是你想要的 |

**结论**：好的用法是「**一个会话专注一个任务，任务内持续迭代**」。

### 1.2 它擅长和不擅长什么

**擅长**：
- 改写、扩写、缩写、翻译
- 从大量文字里提取结构化信息
- 解释概念（尤其是"用类比讲简单"）
- 生成代码草稿、写测试用例
- 挑毛病（审阅、检查遗漏）

**不擅长（需人工把关）**：
- 精确的事实（版本号、日期、具体数字）
- 数学计算（长链条运算容易错）
- 你所在组织的内部上下文（它不知道你们公司的规范）
- 判断"应不应该做"（这是决策，不是信息处理）

## 第 2 课：四个必修练习

### 练习 1：把一句烂提问改成好提问（10 分钟）

**步骤**：
1. 写下你最近一次问 AI 的问题，原样抄下来
2. 对照「角色 + 任务 + 约束 + 输出格式」四要素，标出缺了哪几项
3. 补全后重新问一次
4. 对比两次结果

**验收标准**：第二次的结果里，你不需要再追问"不是这个意思"。

---

### 练习 2：学会"改"而不是"重问"（15 分钟）

**步骤**：
1. 让 AI 写一段 300 字的项目介绍
2. 不要重新问。依次发出三条修正指令：
   - "第二段太正式，改成口语化"
   - "把'赋能''闭环'这类词全去掉"
   - "结尾加一句明确的行动号召"
3. 观察每轮它改了什么、有没有改错地方

**要体会的点**：修正指令越具体，效果越好。"再改好一点"是无效指令。

---

### 练习 3：让它自己检查（20 分钟）

**步骤**：
1. 让 AI 生成一份清单（比如"上线前检查项"）
2. 然后问："这份清单遗漏了哪些常见场景？请补充 5 条，并说明为什么重要"
3. 再问："如果这是一个金融系统而不是普通 Web 应用，上面哪几条要改？"

**要体会的点**：AI 的第一版答案通常是"平均答案"。**追问能把它拉到你的具体场景。**

---

### 练习 4：识别幻觉（15 分钟）

**步骤**：
1. 问一个你很熟悉的领域的具体问题（比如你常用库的某个 API 参数）
2. 看它给出的答案，逐个去官方文档核实
3. 记录：哪几条对、哪几条错、错在哪类信息上

**要体会的点**：错误的类型通常是——**参数名编造、版本号错位、把不同库的用法混在一起**。这告诉你以后哪类信息必须核实。

## 第 3 课：日常工作流模板

把下面三种用法固化下来，覆盖 80% 场景。

### 场景 A：读长文 / 长文档

```
下面是 <文档类型>，请提取：
1. 核心结论（不超过 3 条）
2. 与 <我关心的主题> 相关的部分，原文摘录+所在章节
3. 文档中没有回答但我可能需要知道的问题

<粘贴文档>
```

**关键**：第 3 条能帮你发现文档的盲区。

### 场景 B：写东西前先列提纲

```
我要写 <文档类型>，读者是 <对象>，目的是 <目的>。
先给我 3 个不同角度的提纲，每个标注适用场景。
我选一个之后再展开写。
```

**关键**：先定结构再填内容，比直接生成再大改省一半时间。

### 场景 C：卡住了找人 Review

```
我在做 <事情>，卡在 <具体问题>。
已尝试：<你试过的方法>
怀疑方向：<你的猜测>
请给出 3 个可能的排查方向，按可能性排序，并说明每个的验证方法。
```

**关键**：给出"已尝试"能避免它重复给你无用建议。

## 第 4 课：避坑清单

- [ ] **不要**在对话里贴敏感信息（密码、密钥、身份证号、公司未公开数据）
- [ ] **不要**直接把它生成的代码上线，至少读一遍
- [ ] **不要**用它算重要的数字
- [ ] **要**对任何事实性陈述保持怀疑，直到你核实过
- [ ] **要**把好用的提示词存下来（见 [`../guides/01-personal-prompt-workflow.md`](../guides/01-personal-prompt-workflow.md)）
